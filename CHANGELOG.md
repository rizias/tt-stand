формат основан на [Keep a Changelog](https://keepachangelog.com).

## [Unreleased]

## [0.3.0] — 2026-09-23

### Added

- Команды `metrics query`, `metrics instant`, `metrics labels`, `metrics series` — чтение метрик через тот же посредник источников данных Grafana, что и логи; настройка профиля `grafana.metricsDatasourceUid` для явного выбора источника.
- Флаг `--query-file <путь>` для команд с `--query` — выражение запроса передаётся файлом, минуя искажение оболочкой.
- Поле `echo.ignoredFlags` в каждом ответе: флаги вызова, которые команда не применяет. Такой флаг больше не проходит молча и не становится отказом.

### Changed

- Отказ сервера логов и метрик сообщает текст тела ответа целиком, а не только код состояния; то же теперь верно для списка источников Grafana и для `field_values` при коде 2xx с телом, которое не разобралось как JSON.
- Эхо отказа называет выражение, период и прочие переданные параметры, даже если отказ случился до обращения к серверу — включая случаи, когда отказавшая проверка идёт раньше остальных в разборе аргументов.
- `--limit` проверяется только командами логов, которые его применяют.
- Явно заданный файл конфигурации (`--config` или `TT_STAND_CONFIG`), которого нет, — ошибка `config_invalid` с полным путём, а не молчаливая работа со значениями по умолчанию.
- Повторный `config init` без `--force` ничего не меняет и завершается с кодом 0, называя существующие файлы.
- Пустая строка, `.` или `..` в `grafana.datasourceUid` или `grafana.metricsDatasourceUid` — ошибка `config_invalid`, а не незаданная настройка; идентификатор источника, пришедший из списка Grafana значением `.` или `..`, — `upstream_error`. Идентификатор источника кодируется сегментом пути.
- Файл выражения не в кодировке UTF-8 отвергается с `bad_request`, а не уходит на сервер искажённым.
- Обязательный флаг с пустым значением (например, `--start ""`) уходит на сервер как дан; `bad_request` «не задан» получает только полностью отсутствующий флаг.

### Fixed

- Сетевой путь Windows `\\сервер\ресурс\…` в путях инструмента сохраняет начальный префикс.
- `metrics query`/`metrics instant`: элемент `result` вида `matrix` или `vector`, не являющийся объектом (например `null`), больше не роняет подсчёт `summary.seriesCount`/`summary.pointCount` — такой элемент просто не учитывается в счёте.
- Вывод `--human`: элемент массива `data`, не являющийся объектом (строка, число, `null`), печатается одной строкой своим значением, а не построчно посимвольно и не роняет вывод.
- `logs fields`: элемент перечня `values` ответа `field_values`, не являющийся объектом (например, `null` или строка), больше не роняет команду и не подменяется пустым значением — выводится в данных без изменений.
- `env` и разметка окружений: имя namespace, пришедшее строкой, а не объектом, больше не теряется; элементы без имени (`null`, числа) не роняют команду.
